## 0. 2026-10-03 확정 (사용자 지시: 회사 내부 법률 점검으로 완결)
변호사 검토 대신 법령·고시·판례 기준으로 회사가 직접 점검해 확정했다. 법률 자문이 아니므로, 분쟁이 생기거나 사업 구조가 바뀌면 아래 판단부터 변호사에게 확인한다. 🔸 표시와 화면의 "시행 전 초안" 안내는 모두 지웠다.

**1절 질문에 대한 판단**
1. 결제대행업 등록: 회사가 광고주와 마케팅 서비스 계약, 크리에이터와 용역 계약을 각각 맺고, 단가가 서로 연동되지 않으며, 광고주 입금과 관계없이 회사가 지급 의무를 진다(약관 제3조). 제3자 사이 거래의 대가를 정산하는 구조가 아니므로 개정법(2026-12-17 시행) 기준으로도 등록 대상이 아니라고 본다. 화면·계약 문구가 이 구조와 어긋나지 않게 유지한다(3절).
2·7. 잔액 반환과 선불전자지급수단: 잔액은 회사가 제공하지 않은 서비스의 대가를 돌려줄 의무(또는 회사 서비스에만 쓰는 대금)이고, 제3자의 재화·용역을 살 수 없으며 양도도 막았다(제11조 제5항). 선불전자지급수단(전자금융거래법 제2조 제14호)에 해당하지 않는다고 본다.
3. 미성년자: 만 19세 이상만 이용(제5조), 온보딩에서 확인. 법정대리인 절차는 두지 않는다.
4. 광고 표시: 제14조를 공정위 추천·보증 심사지침에 맞춰 영상 시작 부분 + 설명 첫 부분 모두 표시, 한국어 문구, 플랫폼 기능 병행, 표시 없는 클립은 승인하지 않음으로 강화했다.
5. 면책·관할: 면책을 "고의 또는 과실이 없는 한"으로 고쳐(약관규제법 제7조) 경과실 책임까지 빼지 않게 했다. 관할은 민사소송법 그대로라 문제없다.
6. 리더보드: 활동명·영상·조회수·순위 공개는 처리방침 1절에 적었고, 크리에이터 요청 시 이름을 숨긴다. 정산 금액 자체는 공개 항목에 넣지 않는다.
8. 1년 뒤 반환 제한: 안 쓴 선급금의 반환을 1년 뒤 막는 것은 부당한 조항(약관규제법 제6조·제9조)이 될 수 있어 **5년(상사채권 소멸시효)**으로 바꿨다(2026-10-03 회사 결정, `20261003133409_refund_window_five_years`).
9. 정산 대상 영상·삭제 영상: 규칙을 제출 전에 알리고(약관 제13조), 30일 유지 의무와 함께 운영한다. 30일이 지난 뒤 삭제한 영상도 확인한 주부터 제외하는 규칙은 회사가 유지하기로 했다(2026-10-03). 분쟁이 생기면 이 항목이 가장 다툼 여지가 크다.

**함께 바꾼 것**
- 약관: 회원 통지(제6조의2), 개별 계약 우선(제8조의2, 매니지드 캠페인), 계정 연결(제13조의2), 조회수 확인 방법을 실제 운영대로(제18조), 서비스 일시 중단 안내(제22조), 손해배상(제23조), 탈퇴는 전화·이메일, 서비스 종료 시 잔액 반환(제11조 제6항).
- 처리방침: 서비스 알림, 고객센터 이메일, 광고주 반환 계좌, 알게 된 경로(선택 답변은 동의 근거), 자동화된 결정 없음, 권리 행사 10일 이내 처리, TikTok Pte. Ltd.(싱가포르)·Meta Platforms, Inc.(미국) 국외 이전, 토큰 암호화.

## 1. 변호사에게 물을 것
1. 직접 계약 구조(약관 제3조)로 운영하면 전자지급결제대행업 등록 없이 가능한가. 현행법(~2026-12-16)과 개정법(2026-12-17~) 각각.
2. 광고주의 미사용 선급금을 반환(약관 제11조 제3항)해도 1번 판단에 영향이 없는가, 아니면 다음 캠페인 크레딧으로만 처리해야 하는가.
3. 크리에이터가 만 19세 미만일 때의 계약·지급 방법(법정대리인 동의 절차).
4. 광고 표시 의무(약관 제14조)를 어긴 크리에이터의 게시물에 대해 회사와 광고주가 지는 책임과, 약관으로 줄일 수 있는 범위.
5. 관할 법원 조항(약관 제25조)과 면책 조항(제23조)이 약관규제법상 유효한가.
6. 공개 캠페인 페이지에 크리에이터별 정산 금액(리더보드)을 공개해도 되는가. 동의가 필요한가.
7. 광고주 잔액(중단한 캠페인의 남은 서비스 대금, 다음 캠페인에 쓸 수 있음)이 전자금융거래법상 선불전자지급수단에 해당하는가. 회사 서비스에만 쓸 수 있다.
8. 잔액이 확정된 날부터 1년이 지나면 반환을 막고 다음 캠페인에만 쓰게 하는 조항(약관 제11조 제3항)이 약관규제법상 문제없는가.
9. 캠페인 공개 이후·인증한 본인 계정에 게시한 영상만 인정하고, 삭제·비공개가 확인된 주부터 정산에서 빼는 조항(약관 제13조 제4·5항)이 약관규제법상 문제없는가. 확인한 주에 이미 쌓인 조회수를 지급하지 않는 것이 크리에이터에게 부당하게 불리한가. (2026-10-03 추가)

## 2. 세무사에게 물을 것
1. 크리에이터 용역 대금을 사업소득(업종코드 940306)으로 3.3% 원천징수하는 것이 맞는가.
2. 소액부징수를 지급 1건 단위로 판단하는 것이 맞는가.
3. 광고주 서비스 대금의 부가가치세 처리와 세금계산서 발행 시점(선급 입금 시 vs 서비스 제공 시).
4. 사업자등록이 있는 크리에이터의 처리 방식.

## 3. 직접 계약 구조와 어긋나는 화면 문구
**2026-10-01 반영**: 아래 표에서 '환불' 행과 `campaign_escrow` 이름을 뺀 나머지를 고쳤다. 크리에이터에게는 '예산'이 아니라 '캠페인 지급 한도'로 말한다. 광고주에게 하는 "검증된 조회수만큼만 예산이 쓰여요", 브랜드 화면의 '남은 예산'은 광고주 자신의 서비스 대금이므로 그대로 둔다.

Clipers가 광고주 돈을 맡아 나눠 주는 중개자로 읽히는 문구들이다.

| 위치 | 지금 문구 | 방향 |

## 4. 데이터 노출 (2026-10-01 실제 DB에서 확인)
**진행 상황 (2026-10-01 완료)**: 1단계 `20261001123839_campaign_finances`(브랜드·운영자용 `campaign_finances` 뷰, 공개용 `campaign_payout_limits()`)와 2단계 `20261001124210_close_public_columns`(아래 1·2·4번 권한 회수)를 모두 적용했다. 출시 전이라 배포를 기다리지 않았다. 공개 키로 `brand_cpm`을 조회하면 권한 오류(42501)가 나고, 사이트의 캠페인 목록·상세·리더보드는 정상이다. 3번(크리에이터별 정산 금액 공개)은 변호사 답을 기다린다.
로그인하지 않은 사람(anon)이 API로 직접 읽을 수 있는 것들이다. 화면에 보이지 않아도 공개 키로 누구나 조회할 수 있다.

1. **`campaigns.brand_cpm`, `campaigns.total_budget`**: 공개 캠페인의 브랜드 단가와 총예산. 브랜드 단가는 비공개 원칙이고, 직접 계약 구조에서는 회사 마진이 드러난다. 사이트가 '남은 예산'을 계산하려고 읽는다(`apps/site/lib/campaigns.ts`). → 서버에서 계산한 크리에이터용 수치(남은 지급 한도)만 내보내는 함수로 바꾸고 anon 권한을 회수한다.
2. **`profiles.interests`, `on_camera`, `experience_level`, `terms_agreed_at` 등**: 공개 캠페인에 참여한 크리에이터와 브랜드의 온보딩 답변. 사이트는 `display_name`만 쓴다. → anon 칸 권한을 `id`, `display_name`, `role`로 줄인다.
3. **`settlements.amount`(크리에이터별 정산액)**: 리더보드에 쓰인다. 공개 여부를 1-6번 질문과 함께 정하고 처리방침에 적는다.
4. **`clips.rejection_reason`, `reviewed_by`, `escalation_*`**: 승인된 클립만 공개라서 반려 사유는 보통 비어 있지만, 쓰지 않는 칸은 권한을 회수한다.
