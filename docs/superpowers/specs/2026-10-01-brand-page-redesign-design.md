# 브랜드 페이지 개편 설계

> 2026-10-01 확정. 대상: `/brands`(`apps/site/app/brands/page.tsx`)와 랜딩 공통 팔레트(`packages/ui/src/styles/components.css`의 `.cl-landing`).
> 레퍼런스: contentrewards.com 메인(브랜드용) 페이지. 섹션 골격과 디자인 문법을 따르고, 메시지·문구·비주얼은 Clipers 것으로 만든다.
> 함께 진행 중인 작업: `2026-10-01-advertiser-aeo-design.md`(광고주 FAQ 모듈, `/contact` 상담 문의). 이 문서는 그 결과물을 그대로 쓴다.
> 화면 규칙: `2026-10-01-ui-redesign-design.md` §2. 목업: `.superpowers/brainstorm/`(git 제외).

## 1. 문제와 방향

- 지금 페이지는 섹션 대부분이 "어떻게 돌아가는지, 믿어도 되는지"(검수·조회수 확인·상한·승인)를 설명한다. 정작 **"왜 광고나 인플루언서 섭외 대신 여기에 예산을 써야 하는지"**는 말하지 않는다.
- 새 페이지는 예산을 쓰는 사람이 차례로 품는 의문에 하나씩 답한다. 헛돈이 되지 않나 → 기존 방식과 무엇이 다른가 → 얼마나 수고로운가 → 우리 경우에 맞나 → 돈과 브랜드를 통제할 수 있나 → 조회수를 믿을 수 있나 → 어떻게 시작하나.
- 대상은 세 부류다. 제품 브랜드, 아티스트·레이블, 롱폼 크리에이터·스트리머. 사례 섹션에서 나눠 보여준다.
- 레퍼런스처럼 **모든 비주얼은 실제 제품 화면이거나 실제 크리에이터 영상**이어야 한다. 그라디언트로 채운 장난감 휴대폰, 장식 위젯은 쓰지 않는다.

## 2. 지켜야 할 사실과 제약

| 항목 | 규칙 |
|---|---|
| 브랜드 단가 | 어디에도 쓰지 않는다. **예산 금액과 조회수를 한 화면에 같이 두지 않는다**(실제 생성 폼의 "예상 조회수"도 랜딩에서는 뺀다). 사용률(%)과 조회수는 함께 둘 수 있다(총액이 없으면 역산할 수 없다) |
| 실적·후기 | 만들어 넣지 않는다. 레퍼런스의 고객 인용 섹션은 두지 않는다. "수십 명"처럼 규모를 단정하는 말도 쓰지 않는다 |
| 광고 표시 | 공정위 추천·보증 심사지침상 광고 표시가 필요할 수 있으므로 "광고처럼 안 보인다", "광고가 아니다"는 쓰지 않는다. "크리에이터 각자의 영상"까지만 쓴다 |
| 단계형 섹션 | STEP·번호·로마 숫자를 붙이지 않는다. 흐름 그림은 번호 없이 쓴다 |
| 음악 캠페인 | 제품에는 아직 없다. 크리에이터 페이지와 같이 사례로는 보여준다(제품 추가는 범위 밖) |
| 콘텐츠 유형 이름 | 브랜드 화면은 제품과 같은 "클리핑 / UGC"를 쓴다. 크리에이터 화면의 "소개"는 쓰지 않는다 |
| 검수 시간 | 48시간 |
| FAQ | `ADVERTISER_FAQ`(`apps/site/lib/advertiser-faq.ts`)를 그대로 쓴다 |
| 상담 문의 | `/contact?from=/brands`. 시작 카드와 마무리 섹션에 둔다 |

## 4. 섹션별 문구와 비주얼

### 4.1 히어로
- 제목: **조회수가 난 만큼만,** / **예산을 쓰세요**
- 부제: 크리에이터들이 각자 숏폼을 만들어 올려요. / 예산은 검증된 조회수에만 쓰여요. (두 줄, 한 줄에 한 생각)
- 버튼: 캠페인 시작하기(브랜드 가입) · 진행 중인 캠페인 보기(`/discover`)
- 비주얼: `BrandLiveWindow` 그대로.
- 메타 title: `브랜드 · Clipers — 조회수가 난 만큼만 예산을 쓰는 숏폼 캠페인`
- 메타 description: `크리에이터들이 각자 숏폼을 만들어 올리고, 예산은 검수를 통과한 영상의 검증된 조회수에만 쓰여요. 캠페인은 100만 원부터 열 수 있어요.`

### 4.2 플랫폼 로고 월
- `LogoWall` 그대로.

### 4.3 비교 표 (신규)
- 제목: **섭외하는 대신, 캠페인을 여세요**
- 리드: 같은 예산이어도, 어디에 쓰이는지가 달라요.
- 형태(목업 B안): 왼쪽에 항목 이름 열, 가운데 "인플루언서 섭외" 열(흐린 글자), 오른쪽 "Clipers 캠페인" 열. Clipers 열만 흰 판으로 떠올라 모든 행을 덮는다(요금제 비교표 방식). Clipers 열 머리에는 로고 마크(`/logo/clipers-mark.svg`)를 둔다. 행 사이는 옅은 구분선으로 나눈다.

| 항목 | 인플루언서 섭외 | Clipers 캠페인 |
|---|---|---|
| 비용을 내는 기준 | 섭외할 때 정한 금액 | 검증된 조회수만큼만 |
| 조회수가 나오지 않으면 | 비용은 그대로 나가요 | 예산도 쓰이지 않아요 |
| 만들어지는 영상 | 섭외한 사람 수만큼 | 참여한 크리에이터마다 각자의 영상 |
| 섭외·계약·정산 | 한 명씩 직접 | 검수부터 지급까지 Clipers가 |
| 올라가는 곳 | 크리에이터의 채널 하나 | 7개 숏폼 플랫폼 중 원하는 곳에 |

- 특정 회사 이름이나 수치는 쓰지 않는다.
- 800px 이하: 표 대신 항목마다 한 덩어리로 쌓는다(항목 이름 → "인플루언서 섭외" 값 → "Clipers 캠페인" 값). Clipers 값은 흰 판에 담는다.

### 4.4 해결 카드 3장
- 제목: **정하기만 하면, 나머지는 Clipers가** (그대로)
- 카드 문법: 위쪽에 실제 제품 화면 조각이 떠 있고 아래로 흐려진다(마스크). 그 아래 가운데 정렬 제목과 설명.
- 카드 안 화면은 **실제 앱과 같은 다크 테마**로 그린다. 랜딩 범위(`.cl-landing`)가 토큰을 라이트로 바꾸므로, 제품 조각을 감싸는 요소에서 `.cl-demo`와 같은 다크 토큰을 되살린다(공용 클래스로 뽑아 히어로 창·사례 창·카드 조각·입금 카드가 함께 쓴다). 흐림 마스크는 아래 10% 정도만 둔다.
- 카드 안 화면은 **실제 앱 컴포넌트**(`@clipers/ui`의 `OptionCard`, `Chip`, `Field`·`Input`·`Select`, `StatCard`, `DataTable`, `Badge`, `ProgressBar`)를 써서 그리고, 커서가 실제 제품 흐름대로 누르고 입력한다.

| 카드 | 제목 · 설명 | 화면과 움직임 |
|---|---|---|
| 1 | **예산과 조건만 정하세요** · 캠페인 종류, 올릴 플랫폼, 예산만 정하면 준비가 끝나요. | 브랜드 앱의 **새 캠페인** 편집기. 머리줄 "새 캠페인 · 2/7 완료"와 진행 막대 → 커서가 "클리핑" OptionCard를 고름(3/7) → 플랫폼 Chip 3개(유튜브 쇼츠·틱톡·인스타그램 릴스)를 켬(4/7) → 총예산 입력란에 3000000을 입력(5/7). 반복 |
| 2 | **크리에이터가 만들어요** · 승인된 크리에이터들이 각자 영상을 만들어 올리고, 링크로 제출해요. | 왼쪽 뒤에 실제 크리에이터 영상(`/media/clips/*.mp4`)이 재생되고, 앞에 크리에이터 앱의 **클립 제출** 창("여름밤 후렴 챌린지 · 클립 제출"). 플랫폼 선택 → 영상 링크 입력 → 제출하기 → 알림 "제출했어요 · 검수 대기". 반복 |
| 3 | **나머지는 Clipers가** · 검수, 조회수 집계, 크리에이터 정산과 지급까지 Clipers가 맡아요. | 브랜드 캠페인 화면의 StatCard 2개(검증 조회수가 올라감, 받은 클립 수)와 **받은 클립** 표(크리에이터·플랫폼·검수). 새 줄이 "검수 대기"로 들어왔다가 "승인"으로 바뀐다. 예산 금액은 넣지 않는다 |

- 상태 이름은 제품과 같게 쓴다: 검수 대기(amber) / 승인(brand).

### 4.5 사례 탭 (신규)
- 제목: **이럴 때 캠페인을 열어요**
- 탭(레퍼런스 제품 투어 문법): 아이콘 타일(흰 바탕 둥근 사각형)과 이름이 위아래로 있는 탭 3개. 탭 사이에 세로 구분선이 있고, 아래 가로 트랙에서 고른 탭 구간이 6초 동안 초록으로 차오른 뒤 다음 탭으로 넘어간다. 탭을 누르면 바로 바뀐다.
- 탭 아래 가운데 리드 한 문단, 그 아래 큰 macOS 창(`cl-demo`, 히어로와 같은 다크 앱 화면). 창 안은 **"제출 영상" 화면**이다. 캠페인 종류·이름, 진행 중 표시, 필터(전체·검수 대기·승인과 개수, 앱의 상태 이름과 같게), 9:16 영상 썸네일 5개(아래에 크리에이터·플랫폼 아이콘·조회수·상태).

| 탭 (아이콘) | 리드 | 창 안 캠페인 |
|---|---|---|
| 신제품 알리기 (Package) | 크리에이터들이 제품을 각자 스타일로 소개하는 숏폼을 찍어 올려요. 리뷰, 일상, 상황극처럼 저마다 다른 영상이 한 캠페인에 모여요. | UGC 캠페인 · 데일리 뷰티 신제품 마스카라 소개 · 전체 128 / 검수 대기 6 / 승인 122 |
| 새 음원 알리기 (Music) | 새 음원을 배경음으로 쓰거나 챌린지에 참여한 숏폼이 여러 플랫폼에 동시에 올라와요. 뮤직비디오와 무대 영상을 클리핑할 수도 있어요. | 음악 캠페인 · 신곡 '여름밤' 후렴 챌린지 · 전체 221 / 검수 대기 8 / 승인 213 (히어로 대시보드 수치와 맞춘다) |
| 채널 키우기 (MonitorPlay) | 긴 영상과 방송의 명장면을 크리에이터들이 숏폼으로 편집해 올려요. 숏폼에서 원본 채널로 이어지는 길이 그만큼 많아져요. | 클리핑 캠페인 · 스튜디오 하루 예능 하이라이트 클리핑 · 전체 39 / 검수 대기 2 / 승인 37 |

- 썸네일: `loadShowcaseVideos()`의 실제 유튜브 영상을 쓴다. 신제품 = `ugc`, 새 음원 = `music`, 채널 키우기 = `clipping`. 3:4 칸(숏폼 프로필 격자처럼)에 가운데를 잘라 넣는다(2026-10-02: 섹션 제목부터 창 아래까지 1536×821 한 화면에 들어오도록 탭·리드·창 머리를 줄이고, 필터를 제목 줄 오른쪽으로 옮겼다). API 키가 없거나 실패하면 `/media/clips`의 실제 클립 포스터로 대신한다. 썸네일 위에는 아무것도 얹지 않는다.
- 창 안 브랜드 이름·크리에이터 이름·조회수는 예시 값이고 고정이다. 예산 금액은 넣지 않는다.
- 800px 이하: 탭은 아이콘 없이 가로 세그먼트로 줄이고, 창의 사이드바를 숨기고 썸네일은 2.5칸이 보이도록 가로로 넘긴다.

### 4.6 통제 벤토
- 제목: **정한 대로, 정한 만큼만**
- 문법(레퍼런스 "The best by design."): 5칸 격자에서 줄마다 작은 카드(2칸)와 큰 카드(3칸)를 엇갈려 둔다. 큰 제목(28px)은 왼쪽 위(큰 카드는 왼쪽 가운데)에, 실제 제품 화면 조각은 카드 오른쪽 아래 가장자리에서 잘린다.

| 위치 | 제목 · 설명 | 화면과 움직임 |
|---|---|---|
| 1행 작은 | **꼭 지킬 조건** · 적어 둔 조건이 그대로 검수 기준이 돼요. | 새 캠페인 편집기의 "요구사항" 입력란에 "음원 후렴을 15초 이상 사용 / 영상 설명에 #여름밤챌린지 포함"이 타이핑되고 글자 수(0/500)가 올라간다 |
| 1행 큰 | **클립마다 상한** · 영상 하나가 예산을 독차지하지 않도록, 클립 하나에 쓰일 예산의 상한을 정해요. | "클립당 최대 예산 (원) 300000" 입력란과 클립별 막대 3개. 막대가 차오르고, 꽉 찬 막대에 "상한 도달" 표시 |
| 2행 큰 | **승인된 크리에이터만** · 크리에이터는 캠페인마다 지원하고, 운영팀이 승인한 사람만 영상을 올려요. | 지원한 크리에이터 목록(아바타·이름·분야·플랫폼). "검토 중" 하나가 "승인"으로 바뀐다 |
| 2행 작은 | **남은 예산은 실시간으로** · 예산을 다 쓰면 캠페인이 알아서 끝나요. | 남은 예산(285만원 / 300만원)이 조금씩 줄고 막대가 차오른다. 아래에 "예산을 다 쓰면 · 캠페인 자동 종료". 조회수는 넣지 않는다 |

- 900px 이하: 카드를 한 줄에 하나씩 쌓고, 큰 카드의 문구는 위로 올린다.

### 4.7 검증
- 제목: **검증된 조회수에만** / **예산이 쓰여요**
- 넓은 카드(배경은 히어로와 같은 `MeshGradient`를 카드 안에 깔고 위쪽은 페이지 색으로 녹인다) 안에 흐름 그림 네 칸을 점선으로 잇는다.
  1. 반투명 패널: 유튜브 쇼츠 "조회수 자동 수집", 틱톡 "화면 캡처 대조", 인스타그램 릴스 "화면 캡처 대조"(실제 플랫폼 아이콘)
  2. 동심원과 사람·체크 아이콘(파문이 천천히 퍼진다)
  3. 살짝 기운 칩 3개: 요구사항 · 조회수 대조 · 급증 감지(상태 점)
  4. 결과 패널: 검증된 조회수(48,200회에서 조금씩 올라감)
- 그 아래 칸 이름: 플랫폼 데이터 · 사람이 직접 검수 · 이상 여부 확인 · 검증된 조회수만 정산. 번호는 붙이지 않는다.
- 카드 아래 2×2 칸(옅은 구분선, 아이콘 없음). 굵은 첫 문장에 회색 설명이 이어진다:
  - **사람이 직접 검수해요.** 올라온 영상은 운영팀이 48시간 안에 요구사항대로인지 확인해요. 통과한 영상만 정산돼요.
  - **플랫폼에 맞게 확인해요.** 유튜브는 조회수를 자동으로 가져오고, 다른 플랫폼은 크리에이터가 낸 화면 캡처와 대조해요.
  - **급증은 따로 봐요.** 짧은 시간에 비정상적으로 늘어난 조회수는 정산 전에 따로 확인해요.
  - **걸러진 조회수엔 쓰이지 않아요.** 검증을 통과한 조회수만큼만 예산이 쓰여요.
- 900px 이하: 흐름 그림은 세로로 쌓고 점선도 세로로 바꾼다. 2×2는 한 열로 쌓는다.

## 5. 랜딩 팔레트 (웜 베이지 → 애플 뉴트럴)

카드가 누렇게 떠 보여서 `.cl-landing` 토큰을 무채색으로 바꾼다(목업 A안). **랜딩 공통 토큰이라 크리에이터 페이지, 가이드, `/contact`, 마켓(`(market)`)도 함께 바뀐다.**

| `--color-background` | #fffdfb | #ffffff |
| `--color-panel` | #f6f2ec | #f5f5f7 |
| `--color-field`, `--gray-3` | #efe9e2 | #ebebef |

- `components.css` 안에 웜 색이 직접 적힌 곳(약 29곳: `rgba(31, 26, 20, …)` 그림자, 상단 메뉴 `rgba(255, 253, 251, 0.8)` 등)도 같은 무채색으로 바꾼다.

- 다크 앱 화면(`cl-demo`, 제품 창)은 바꾸지 않는다.

## 8. 확인 방법
- 타입 검사와 기존 테스트, 새 순수 함수 테스트가 통과한다.
- `/brands`를 1440×900과 390px에서 캡처해 섹션 순서, 데모 움직임, 줄바꿈, 흐림 마스크가 잘리지 않는지 본다. 움직임 줄이기 설정에서는 모든 데모가 멈춘 상태로 보인다.
- 크리에이터 페이지 `/`, `/guides`, `/contact`, `/discover`를 같은 폭에서 캡처해 팔레트 교체 뒤 베이지가 남은 곳이 없는지 본다(`rg "31, 26, 20|fffdfb|f6f2ec" packages apps --glob '!**/.next/**'` 결과가 없어야 한다).
- 브랜드 페이지 소스와 렌더링된 HTML에 브랜드 단가(3,000원·`brandCpm`)가 나오지 않는다. 예산 금액과 조회수가 같은 화면 조각 안에 함께 있지 않다.
