# 광고주 AEO 설계 — 하위 프로젝트 B

> 2026-10-01 확정. 크리에이터 가이드(`2026-10-01-creator-guides-aeo-design.md`)의 틀 위에 광고주용 가이드 16개, 광고주 FAQ 공용 모듈, 상담 문의 폼, 신뢰 구조화 데이터, 양쪽 가이드 연결을 더하고, 크리에이터 가이드의 공통 부분을 줄인다.
> 구현은 두 계획으로 나눈다: **B1** 광고주 FAQ 모듈 + 상담 문의 폼 + 구조화 데이터, **B2** 광고주 가이드 16개 + 연결 + 크리에이터 가이드 간결화.

## 1. 목표와 원칙

- 광고주가 AI에게 **자기 업종이나 문제로** 물었을 때("신곡 홍보 어떻게 해?", "예능 클립 바이럴", "광고비를 성과만큼만 쓰는 법") Clipers가 답과 출처로 뽑히게 한다.
- 크리에이터 가이드와 같은 원칙: 질문형 제목, 바로 인용할 한 줄 답, 그 업종·문제만의 고민에 대한 답, 확인된 사실만.
- 상담을 원하는 광고주(방송국·지자체·에이전시·대형 브랜드)가 이탈하지 않도록 상담 문의 창구를 둔다.
- **비용 질문:** 단가는 쓰지 않는다. 대신 "100만 원부터, 검증된 조회수만큼만 예산이 쓰이고, 캠페인을 만들 때 예산을 넣으면 예상 조회수를 바로 보여 준다"로 답한다(캠페인 생성 화면 `campaign-form.tsx`의 예상 조회수 표시가 근거).
- 쓰지 않는 것: 브랜드 단가와 크리에이터 단가(광고주 쪽에 둘 다 보이면 수수료가 드러남), 지어낸 성과 수치·사례·고객사, 성과 보장, 확인되지 않은 기능(에이전시 다중 고객 관리, 공공기관 계약 절차, 세금계산서 발행 방식 등), 음원을 쓰는 음악 캠페인이 지금 된다는 표현(준비 중).

## 2. 광고주 FAQ 공용 모듈

`apps/site/lib/advertiser-faq.ts` — `ADVERTISER_FAQ: { id, q, a }[]`와 `advertiserFaqById`. 브랜드 페이지(`/brands`)의 인라인 FAQ를 대체하고, 광고주 가이드와 llms.txt가 함께 쓴다.

| id | 질문 | 답 |
|---|---|---|
| `min-budget` | 최소 예산이 있나요? | 캠페인은 100만 원부터 열 수 있어요. 상한은 없어요. |
| `cost` | 비용은 어떻게 계산되나요? | 검수를 통과한 영상의 검증된 조회수만큼만 예산이 쓰여요. 조회수가 나오지 않으면 예산도 쓰이지 않아요. |
| `expected-views` | 예산으로 조회수가 얼마나 나오나요? | 캠페인을 만들 때 예산을 넣으면 예상 조회수를 바로 보여 드려요. 실제 조회수는 올라온 영상의 반응에 따라 달라져요. |
| `clip-cap` | 영상 하나에 예산이 몰리지는 않나요? | 클립 하나가 받을 수 있는 금액에 상한을 둘 수 있어요. 한 영상이 예산을 독차지하지 않아요. |
| `budget-exhausted` | 예산이 다 쓰이면 어떻게 되나요? | 검증된 조회수만큼 예산이 다 쓰이면 캠페인이 끝나요. 남은 예산은 언제든 실시간으로 확인할 수 있어요. |
| `leftover` | 다 못 쓴 예산은 어떻게 되나요? | 캠페인을 마친 뒤 상담 문의로 요청하면, 쓰지 않은 예산을 환불받거나 다음 캠페인으로 옮길 수 있어요. |
| `start-time` | 캠페인은 언제 시작되나요? | 캠페인을 만들고 예산을 입금하면, 운영팀이 입금을 확인한 뒤 바로 공개돼요. |
| `review-time` | 올라온 영상은 얼마나 빨리 검수하나요? | 캠페인을 만들 때 24시간이나 48시간 중에서 고를 수 있어요. 운영팀이 그 안에 요구사항대로인지 확인해요. |
| `creators` | 어떤 크리에이터가 참여하나요? | 크리에이터는 캠페인마다 지원하고, 운영팀이 승인한 사람만 영상을 올릴 수 있어요. |
| `view-verification` | 조회수는 어떻게 확인하나요? | 유튜브는 조회수를 자동으로 수집하고, 다른 플랫폼은 크리에이터가 낸 화면 캡처를 운영팀이 대조해요. 짧은 시간에 비정상적으로 늘어난 조회수는 따로 확인해요. |
| `platforms` | 어떤 플랫폼을 지원하나요? | 유튜브 쇼츠, 틱톡, 인스타그램 릴스, 페이스북, X, 네이버 클립, 카카오 숏폼이에요. 캠페인마다 올릴 플랫폼을 고를 수 있어요. |
| `music` | 음원을 쓰는 음악 캠페인도 열 수 있나요? | 음원을 배경음으로 쓰는 음악 캠페인은 준비하고 있어요. 지금은 무대나 뮤직비디오 영상을 편집하는 클리핑 캠페인으로 열 수 있어요. |

- 정책 숫자는 `@clipers/db` 상수에서 가져온다(`MIN_CAMPAIGN_BUDGET`, `REVIEW_SLA_OPTIONS`).
- 무결성 테스트: id 중복 없음, 단가 문구 없음("1천 회당" 금지, `DEFAULT_PRICING.brandCpm`·`creatorCpm`의 원 단위 금액 문자열 금지).

## 3. 상담 문의 폼

**페이지:** `/contact` — 제목 "상담 문의", 리드 "캠페인 구성, 예산, 일정이 궁금하면 남겨 주세요. 운영팀이 이메일로 답해 드려요." 브랜드 페이지(마지막 CTA 옆), 광고주 가이드의 버튼, 브랜드 푸터에서 연결.

**입력 항목**
| 항목 | 필수 | 제한 |
|---|---|---|
| 회사·기관명 | 필수 | 1~100자 |
| 담당자 이름 | 필수 | 1~50자 |
| 이메일 | 필수 | 이메일 형식, 200자 이하 |
| 전화번호 | 선택 | 30자 이하 |
| 업종 | 필수 | 광고주 업종 11개 + 기타 중 선택 |
| 문의 내용 | 필수 | 10~2,000자 |
| 개인정보 수집·이용 동의 | 필수 | 체크 |

- 동의 문구: "수집 항목: 회사·기관명, 담당자 이름, 이메일, 전화번호(선택) · 목적: 상담 문의 답변 · 보유 기간: 답변 후 1년 뒤 삭제. 동의하지 않으면 문의를 남길 수 없어요."
- 스팸 방지: 사람에게 보이지 않는 입력칸(허니팟). 값이 있으면 저장하지 않고 성공처럼 응답한다.
- 처리: 서버 액션이 입력을 검증(`validateInquiry`, 순수 함수 + 테스트) → `inquiries` 테이블에 저장(사이트의 공개 키, RLS로 추가만 허용) → `SLACK_WEBHOOK_URL`이 있으면 기존 `sendSlackNotification`으로 운영팀 알림(실패해도 저장은 유지). 완료 후 "문의를 받았어요. 영업일 기준으로 이메일로 답해 드릴게요."를 보여 준다.
- DB: 새 테이블 `public.inquiries`(`id uuid pk`, `created_at`, `company`, `contact_name`, `email`, `phone`, `industry`, `message`, `source_path`, `consented_at`), 각 열에 길이 `check`. RLS 켜고 `anon`·`authenticated`에 **insert만** 허용(조회·수정·삭제 정책 없음). 운영팀은 Supabase 대시보드와 슬랙에서 확인한다.
- 환경변수: 사이트에 `SLACK_WEBHOOK_URL`(서버 전용) 추가. 없으면 알림만 건너뛴다.

## 4. 광고주 가이드 16개

주소는 `/guides/<slug>`(크리에이터 가이드와 같은 공간). 화면은 브랜드용 상단 메뉴(`LandingChrome path="/brands" cta="캠페인 시작하기"`).

**틀(간결형):** 질문형 제목 → 한 줄 답 → 고유 본문 3~4단락 → 공통 안내 2줄("캠페인은 100만 원부터 열 수 있고, 검증된 조회수만큼만 예산이 쓰여요." / "캠페인을 만들 때 예산을 넣으면 예상 조회수를 바로 확인할 수 있어요.") → 버튼(캠페인 시작하기 → 브랜드 가입, 상담 문의 → `/contact`) → FAQ 3개(광고주 FAQ에서) → 관련 가이드 3개. 크리에이터 캠페인 카드는 넣지 않는다.

## 5. 연결과 신뢰

- **목록 페이지 `/guides`:** "크리에이터"와 "광고주" 두 부분으로 나누고, 각 부분 안에서 묶음별 목록.
- **양쪽 연결:** 가이드 데이터에 `counterpart?: string`(반대편 가이드 slug)을 두고, 본문 끝에 "크리에이터라면 →" / "광고주라면 →" 한 줄 링크. 짝: `for-streamers`↔`fan-edits`, `for-music`↔`fan-edits`, `for-broadcasters`↔`copyright-safe-clipping`, `clipping-marketing`↔`what-is-clipping`, `verified-views`↔`is-it-legit`. 광고주의 비용 페이지(`pay-per-view`)는 크리에이터 금액 표(`shorts-earnings-calculator`)와 잇지 않는다(두 단가가 나란히 놓이지 않게).
- **브랜드 페이지:** FAQ를 광고주 FAQ 모듈로 바꾸고, 마지막 CTA에 "상담 문의" 버튼, 푸터 가이드 링크는 공통.
- **Organization 구조화 데이터(`apps/site/app/layout.tsx`):** `address`(PostalAddress, 사업장 주소), `taxID`(사업자등록번호)를 `COMPANY`에서 추가.
- **llms.txt:** "브랜드·아티스트" 섹션을 광고주 FAQ 요약과 광고주 가이드 목록으로 확장, 상담 문의 링크 추가.
- **사이트맵:** `/contact`, 광고주 가이드 16개.
