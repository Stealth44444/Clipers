# 크리에이터 페이지 메시지·구조 개편 설계

> 2026-10-01 확정. 대상: `/` 크리에이터 페이지(`apps/site/app/page.tsx`)와 이 결정 때문에 함께 바뀌는 제품 문구·정책.
> 이전 문구 기준: `2026-10-01-landing-copy-draft.md`. 화면 규칙: `2026-10-01-ui-redesign-design.md` §2.

## 1. 문제와 방향

- 국내 숏폼 크리에이터에게 "클리핑"은 낯선 개념이다. 지금 페이지는 **언제·어떻게 받는지**(정산·지급·검수)를 먼저 말하고, **무엇을 만드는지**는 맨 아래 캠페인 종류 섹션에서 한 줄로만 설명한다.
- 타깃은 세 부류 모두다: 채널 없이 편집할 줄 아는 사람, 이미 쇼츠 채널을 운영하는 사람, 하이라이트 채널 운영자. 공통된 고민은 "수익창출 조건을 채우기 전에는 숏폼으로 돈을 벌 수 없다"는 것이고, 예전 음원협업 생태계가 사라져 그 공백이 비어 있다.
- 그래서 페이지의 중심 메시지는 **"구독자 0명부터, 조회수만큼 받는다"**이다. 방문자가 궁금해하는 순서(왜 나에게 좋은지 → 무엇을 만드는지 → 지금 무엇이 열려 있는지 → 믿어도 되는지)로 섹션을 다시 놓는다.

## 2. 확정된 사실 (문구의 근거)

| 항목 | 내용 | 페이지에서 쓰는 방식 |
|---|---|---|
| 참여 자격 | 구독자 조건이 없고, 새 채널도 된다 | "구독자 0명부터", "구독자 조건 없음"을 명시한다 |
| 클리핑 영상 권한 | 원작자가 사용을 허락한다. 클레임·경고 대응은 정해지지 않았다 | "원작자가 허락한 영상만"까지만 쓴다. "저작권 걱정 없음", "클레임 보호" 같은 약속은 쓰지 않는다 |
| 음악 캠페인 | 제품에 추가할 예정이다 | 페이지에 남긴다. 제품 추가는 별도 작업이다 |
| 검수 시간 | **최대 48시간**으로 바꾼다 | 모든 페이지에서 "48시간 안에"로 쓴다 (§5 제품 변경) |
| 단가 | 크리에이터 단가(1천 회당 800원)만 공개한다 | 브랜드 단가는 어디에도 쓰지 않는다 |
| 카카오 플랫폼 이름 | **카카오 숏폼** | "카카오 쇼츠"를 모두 바꾼다 |
| 예산 소진 | 예산이 다 쓰이면 캠페인이 끝난다(2026-10-01 확정). 자동 종료 로직은 아직 없다(별도 작업) | "예산이 다 쓰이면 캠페인이 끝나요"를 쓴다 |

## 3. 섹션 구조

기존 섹션은 모두 유지하고, 비주얼과 구현도 그대로 둔다. 바뀌는 것은 문구와 순서, 그리고 새 섹션 하나다.

| 순서 | 섹션 | 변경 |
|---|---|---|
| 1 | 히어로 (휴대폰 + 정산 카드) | 문구 |
| 2 | 로고 월 + 로테이팅 제목 | 문구, 컴포넌트에 뒤쪽 고정 문구 추가 |
| 3 | **클리핑 설명** | **신규** |
| 4 | 캠페인 종류 (클리핑·소개·음악) | 문구, 위치 이동 (원래 6번째) |
| 5 | 지금 모집 중인 캠페인 | 한 칸 아래로. **캠페인이 4개 이상일 때만 표시** |
| 6 | 벤토 "간단하고, 투명하게" | 카드 문구 일부 |
| 7 | FAQ | 질문 추가·정리 |
| 8 | 마지막 CTA 카드 | 문구 |

- 5번 기준 숫자 4는 데스크톱에서 카드 한 줄이 차는 수다. 구현할 때 실제 레일 폭으로 확인하고, 상수 하나로 둔다.
- 5번이 숨겨져 있는 동안에도 히어로와 CTA의 "캠페인 둘러보기" 버튼으로 `/discover`에 갈 수 있다.

## 4. 섹션별 문구

### 4.1 히어로
- 제목: **구독자 0명부터,** / **조회수만큼 받으세요**
- 부제: 알리고 싶은 영상이 있는 곳과 크리에이터를 이어 드려요. 숏폼으로 만들어 올리면, 새 채널이어도 조회수만큼 받아요.
- 버튼: 무료로 시작하기 · 캠페인 둘러보기 (그대로)
- 메타 title: `Clipers — 구독자 0명부터, 숏폼 조회수만큼 받으세요`
- 메타 description: `구독자 수와 상관없이 캠페인에 참여하고, 올린 숏폼의 조회수만큼 정산받으세요. 가입과 지원은 무료예요.`
- 히어로에서는 "브랜드 캠페인", "검증된 조회수"처럼 처음 보는 사람에게 낯선 말을 쓰지 않는다.

### 4.2 로고 월 위 로테이팅 제목
- 문구: **[새 채널이어도 / 수익창출 전이어도 / 숏폼이 처음이어도]** 여기에 올리면 돼요
- 아래 플랫폼 로고들이 "여기"를 가리킨다.
- `rotating-headline.tsx`는 지금 `고정 앞말 + 바뀌는 말` 구조다. 이를 `바뀌는 말 + 고정 뒷말`로 쓸 수 있게 고친다. 바뀌는 말의 폭에 맞춰 줄이 흔들리지 않는 동작은 그대로 유지한다.
- 움직임 줄이기 설정과 스크린 리더에는 한 문장으로 읽힌다: "새 채널이어도, 수익창출 전이어도, 숏폼이 처음이어도 여기에 올리면 돼요"

### 4.3 클리핑 설명 (신규)
- 제목: **찍지 않아도, / 편집만으로**
- 본문: 클리핑은 캠페인이 정해 준 영상을 내 방식대로 편집해 숏폼으로 올리는 일이에요. 자르고, 자막을 넣고, 순서를 바꾸는 것까지 자유예요.
- 둘째 문단(예산 개념): 캠페인은 영상을 알리고 싶은 쪽이 예산을 걸고 여는 요청이에요. 참여한 크리에이터들이 각자 올린 영상의 조회수만큼 이 예산을 나눠 받고, 예산이 다 쓰이면 캠페인이 끝나요.
- 그 아래 예산 카드: 마켓 캠페인 카드의 예산 줄과 같은 구성(남은 예산 320만원 / 500만원, 아바타 묶음과 참여 42명, 사용률 막대). 고정 값이며 받을 금액과 함께 움직이지 않는다.
- 가독성: 문구 칸 360px, 짧은 두 문단(문단 사이 간격), 17px·행간 1.75. 원본 종류 나열은 비주얼이 대신한다.
- 쓰지 않는 표현: 음원협업 언급, "원본", "명장면"으로만 한정하는 정의, 저작권 보장.
- 예산은 숫자로 움직이지 않는다. 공개된 "남은 예산"은 브랜드 단가로 줄어들기 때문에, 받을 금액과 줄어드는 예산을 나란히 보여주면 브랜드 단가를 역산할 수 있다.
- 배치(2026-10-01 수정): 로고 월(가운데 정렬) 다음이라 문구는 왼쪽, 비주얼은 오른쪽에 두는 좌우 배치. 1100px 이하에서는 문구 위·비주얼 아래, 800px 이하에서는 비주얼도 세로로 쌓는다.
- 비주얼: 단계 번호와 화살표 없이 한 장면으로 보여준다.
  - 왼쪽 macOS 창(`cl-demo`): 롱폼 시청 화면. 플레이어 위 컨트롤(빨간 재생 막대와 같은 굵기로 클립 구간 1:52–2:26을 초록으로 표시, 재생·다음·볼륨·시간·자막·설정·전체화면), 아래에 제목·채널·구독자 수·구독 버튼.
  - 오른쪽 `DeviceFrame` 휴대폰: 같은 구간을 편집한 숏폼. 훅 문구("POV: 신차 시승을 사막에서 함", 핵심 단어 노란색), 장면마다 바뀌는 자막, 숏폼 UI(좋아요·댓글·공유, 핸들·캡션·해시태그·음원, 진행선).
  - 넓은 화면에서는 창의 위·아래 끝을 휴대폰 프레임과 맞춘다(창이 휴대폰 높이로 늘어나고 플레이어가 남는 높이를 채운다).
  - 휴대폰 아래: 올라가는 조회수와 받을 금액(`DEFAULT_PRICING.creatorCpm`으로 계산).
  - 움직임 줄이기 설정에서는 영상·숫자·자막 전환을 멈춘다.

### 4.4 캠페인 종류
비주얼(실제 유튜브 영상 카드, 스크롤 고정, 진행 막대)은 그대로 두고 문구만 바꾼다. 받는 방식은 위에서 이미 말했으므로 반복하지 않고, 각 종류가 **어떤 크리에이터에게 맞는지**로 끝맺는다.

| id | 라벨 | 문구 |
|---|---|---|
| clipping | 클리핑 | **클리핑 캠페인.** 캠페인이 정해 준 영상을 내 방식대로 편집해 숏폼으로 만들어요. 얼굴을 드러내지 않아도, 편집만 할 줄 알면 시작할 수 있어요. |
| ugc | 소개 | **소개 캠페인.** 제품이나 서비스를 내 스타일대로 소개하는 숏폼을 찍어요. 리뷰, 일상, 상황극 무엇이든 괜찮아요. |
| music | 음악 | **음악 캠페인.** 정해진 음원을 배경음으로 쓰거나 챌린지에 참여해요. 춤, 립싱크, 브이로그 무엇이든 괜찮아요. |

- 소개 캠페인은 제품을 직접 써 보지 않아도 된다. "써 보고", "후기"처럼 사용을 전제하는 말은 쓰지 않는다.

### 4.5 지금 모집 중인 캠페인
- 문구는 그대로: "지금 모집 중인 캠페인 · 남은 예산이 많은 캠페인부터 보여요. 모든 캠페인 보기"
- 표시 조건만 `campaigns.length > 0`에서 `campaigns.length >= 4`(상수)로 바꾼다.

### 4.6 벤토 "간단하고, 투명하게"
제목과 다섯 카드의 비주얼은 그대로 둔다.

| 카드 | 문구 |
|---|---|
| 간단하게 | 정산된 금액이 3,000원을 넘으면, 버튼 한 번으로 지급을 요청해요. |
| 자유롭게 | (그대로) 관심 있는 분야와 내가 쓰는 플랫폼에 맞는 캠페인만 골라요. |
| 빠르게 | 올린 영상은 48시간 안에 검수하고, 통과하면 바로 조회수 집계가 시작돼요. 링 비주얼: **48시간** |
| 끝없이 | 조회수가 1,000회를 넘으면 그전 조회수까지 모두 정산되고, 그 뒤로 늘어난 조회수도 매주 이어서 받아요. |
| 투명하게 | (그대로) 조회수와 정산 금액, 지급 내역을 한곳에서 확인해요. |

### 4.7 FAQ (순서대로)
1. **클리핑이 뭔가요?** 캠페인이 정해 준 영상을 내 방식대로 편집해 숏폼으로 올리는 일이에요. 올린 영상의 조회수만큼 정산돼요.
2. **구독자가 적거나 새 채널이어도 되나요?** 네. 구독자 수나 수익창출 여부와 상관없이 누구나 지원할 수 있어요. 캠페인마다 운영팀이 지원을 확인한 뒤 승인해요.
3. **남의 영상을 올려도 괜찮은가요?** 클리핑 캠페인은 원작자가 사용을 허락한 영상만 다뤄요. 캠페인에 적힌 요구사항에 맞춰 편집해 주세요.
4. **가입비나 지원 비용이 있나요?** (그대로)
5. **얼마를 받나요?** (기존 답) + 예를 들어 1천 회당 800원인 캠페인이라면, 조회수 10만 회에 8만 원이에요. (금액은 `DEFAULT_PRICING.creatorCpm`으로 계산)
6. **조회수가 얼마나 나와야 정산되나요?** (그대로)
7. **언제 돈을 받을 수 있나요?** (그대로)
8. **어떤 플랫폼에 올리면 되나요?** (그대로, "카카오 쇼츠" → "카카오 숏폼")
9. **조회수는 어떻게 확인하나요?** (그대로)

- 기존 "아무나 참여할 수 있나요?"는 2번으로 합친다.
- FAQ 구조화 데이터(JSON-LD)는 같은 목록에서 만들어지므로 따로 맞출 필요가 없다. 구현할 때 확인한다.

### 4.8 마지막 CTA 카드
- 제목: **수익창출을 기다리지 말고,** / **오늘부터 받으세요**
- 리드: 가입과 지원은 무료예요. 새 채널로도 지금 바로 시작할 수 있어요.
- 사실 3개: 구독자 조건 없음 · 조회수 1,000회부터 정산 · 48시간 안에 검수 (아이콘은 Lucide, 첫 항목은 `UserRound`)
- 버튼: 무료로 시작하기 · 캠페인 둘러보기 (그대로)

## 5. 함께 바뀌는 제품 문구·정책

| 변경 | 위치 |
|---|---|
| 검수 시간 선택지 `[24, 48, 72]` → `[24, 48]` | `packages/db/src/campaignDraft.ts` `REVIEW_SLA_OPTIONS`, 브랜드 캠페인 생성 폼, 관련 테스트 |
| 이미 72시간으로 저장된 캠페인 처리 | 구현 계획에서 실제 데이터를 확인한 뒤 정한다. 기본안은 마이그레이션으로 48시간으로 낮추는 것이다 (DB 제약은 `> 0`뿐이라 스키마 변경은 없다) |
| 브랜드 페이지 검수 문구 "72시간 안에", "24~72시간" → 48시간 기준 | `apps/site/app/brands/page.tsx` |
| 크리에이터에게 보이는 UGC 라벨 → "소개" | `apps/app/app/creator/campaigns/page.tsx`, `apps/app/app/onboarding/onboarding-flow.tsx`. 브랜드·관리자 화면과 DB 값 `ugc`는 그대로 |
| "카카오 쇼츠" → "카카오 숏폼" | `packages/db/src/platforms.ts`, `apps/site/components/logo-wall.tsx`, 크리에이터·브랜드 FAQ |

- `CONTENT_TYPE_LABEL`(`apps/app/lib/status.ts`)은 브랜드·관리자·크리에이터 화면이 함께 쓴다. 크리에이터용 라벨(`CREATOR_CONTENT_TYPE_LABEL`, ugc = '소개')을 따로 두고 크리에이터 화면만 그것을 쓴다.
- `apps/site`는 지금 콘텐츠 유형 라벨을 화면에 보여주지 않는다(`lib/campaigns.ts`에서 값만 읽는다). 구현할 때 다시 확인한다.

## 6. 범위 밖
- 음악 캠페인을 제품(DB `contentType`, 브랜드 생성 폼)에 추가하는 작업.
- 클리핑 영상의 클레임·경고 대응 정책. 정해지면 FAQ 3번에 추가한다.
- 브랜드 페이지의 메시지 개편(이번에는 검수 시간과 카카오 이름만 맞춘다).

## 7. 지켜야 할 규칙
- 단계 번호(STEP 1·2·3), 체크 표시 나열, 대문자·영문 아이브로, 장식용 그라디언트와 위젯은 쓰지 않는다.
- 문장은 존댓말 해요체, 짧게. 확정되지 않은 수치나 실적은 쓰지 않는다.
- 브랜드 단가는 어디에도 쓰지 않는다.

## 8. 확인 방법
- `pnpm` 타입 검사와 기존 테스트(`campaignDraft.test.ts` 포함)가 통과한다.
- 크리에이터 페이지를 1440×900과 390px 폭에서 확인한다: 섹션 순서, 새 설명 섹션의 비주얼, 로테이팅 제목 줄 흔들림, 움직임 줄이기 설정.
- 모집 중 캠페인이 3개일 때는 섹션이 숨겨지고 4개일 때는 보이는지 확인한다.
- `rg "72시간|24~72|카카오 쇼츠"` 결과가 문서(`docs/`) 밖에서 없다.
