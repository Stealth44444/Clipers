## 1. 문제와 방향

- 지금 페이지에서 "왜 클리핑인가"를 말하는 섹션은 히어로, 데이터 섹션(`ViewsStory`), 비교 표 셋뿐이고, 셋 다 **손실 방어**(조회수가 안 난 영상엔 돈을 안 낸다)만 말한다. 나머지 다섯 섹션은 사용법과 운영 이야기다.
- 빠진 것은 **공격 논리**: 크리에이터 여럿이 각자 영상을 올리면 같은 예산으로 더 크게 퍼질 기회가 생긴다는 것. 이 섹션이 그 자리를 맡는다.
- 메시지는 둘이다. ① 숏폼 추천은 계정이 아니라 영상 단위라서, 영상 수가 곧 기회 수다. ② 크리에이터마다 장면·첫 3초·자막이 달라서, 무엇이 먹히는지 조회수로 드러난다.
- 생김새는 **크리에이터 페이지의 캠페인 종류 섹션(`CampaignTypes`, `cl-kinds`)과 같은 문법**으로 맞춘다. 별도 차트·영상 그리드·장식 위젯은 쓰지 않는다(목업 1·2차에서 "바이브코딩스럽다", "크리에이터 페이지와 일관성이 떨어진다"로 탈락).
- 페이지 길이를 늘리지 않도록 사용법 섹션 두 개(해결 카드, 통제 벤토)를 하나로 합친다.

## 2. 근거와 제약

| 항목 | 내용 |
|---|---|
| 추천은 영상 단위 | TikTok Newsroom, "How TikTok recommends videos #ForYou", 2020년 6월 18일. 원문: "neither follower count nor whether the account has had previous high-performing videos are direct factors in the recommendation system." 원문 확인함 |
| 히트 확률 | 영상 N편 중 하나 이상이 상위 20%에 들 확률 = 1 − 0.8ᴺ. N = 10 → 89%. `views-math.ts`의 `hitProbability(10)`. 영상마다 같은 분포를 따른다고 가정한다(페이지에는 쓰지 않는다) |
| 쓰지 않는 근거 | 인스타그램 2024년 4월 랭킹 변경(공식 원문 링크를 못 찾음), Nielsen "크리에이티브가 매출 상승의 47%"(원문 본문에서 수치 확인 불가) |
| 광고 표시 | "광고처럼 안 보인다", "광고가 아니다"는 쓰지 않는다(공정위 추천·보증 심사지침) |

| 브랜드 단가 | 이 섹션에는 금액을 하나도 두지 않는다(조회수만 있다) |

## 3. 페이지 순서 (바뀐 부분)

히어로 → 데이터 섹션 → **영상이 퍼진다(신규)** → 비교 표 → 사례 탭 → **정하기만 하면(해결 카드 + 통제 벤토 통합)** → 검증 → 시작 카드 → FAQ → 마무리.

- 통합 섹션은 사례 탭 뒤로 간다. "왜 → 다른 점 → 우리 경우에 맞나 → 어떻게 굴러가나 → 믿을 수 있나 → 시작" 순서가 된다.

## 4. 신규 섹션: 영상이 퍼진다

### 4.1 형태
- `CampaignTypes`와 같다. 넓은 화면에서 무대가 고정(sticky)되고, 스크롤에 따라 장면 세 개가 차례로 바뀐다. 아래에 세그먼트 진행 표시(누르면 그 장면으로 이동). 한 번의 휠 동작이 한 장면을 넘긴다. 860px 이하에서는 고정 없이 세 장면을 차례로 쌓는다.
- 각 장면: 왼쪽에 Lucide 아이콘 + **굵은 첫 문장** + 회색으로 이어지는 문장(`cl-kinds__text`와 같은 크기·색). 오른쪽에 실제 제품 화면.
- 섹션 제목(h2)은 화면에 보이지 않는 낭독기용으로 둔다: "한 명 대신, 여러 크리에이터가 동시에 올려요". 크리에이터 페이지와 같이 보이는 제목 없이 문장이 곧 제목이다.

### 4.2 장면

| 장면 | 아이콘 | 문장 | 오른쪽 화면 |
|---|---|---|---|
| 1 | `Users` | **한 명 대신, 여러 크리에이터가 동시에 올려요.** 서로 다른 계정과 플랫폼에서 영상이 한꺼번에 올라와요. 한 사람의 팔로워에만 머물지 않아요. | 크리에이터 페이지 "투명하게" 카드와 같은 macOS 알림(`cl-notice`)을 겹치지 않고 펼친 목록 다섯 개. 각 알림: Clipers 마크 · "새 클립" · 시간(방금 / 1분 전 / 1분 전 / 3분 전 / 4분 전) · 플랫폼 아이콘 + "하린님이 릴스에 영상을 올렸어요."(하린·릴스, 도윤·유튜브 쇼츠, 서아·틱톡, 민준·네이버 클립, 지우·카카오 숏폼). 장면이 켜질 때마다 아래(오래된 것)부터 하나씩 0.52초 간격으로 들어온다. 서버 HTML, 움직임 줄이기, 860px 이하에서는 다섯 개가 모두 보인다 |
| 2 | `Layers` | **영상이 많을수록, 터질 기회도 많아요.** 영상 10편이면 그중 하나가 상위 20%에 들 확률이 89%예요. 빗나간 영상엔 예산이 쓰이지 않아요. | 같은 경기를 다르게 편집한 실제 클립 세 개를 아이폰 세 대에. 가운데 앞 `hoops-close`(@hoopclip, "이게 들어간다고?"), 좌우 뒤 0.82배 `hoops-slow`(@court.cuts, "끝까지 보면 소름"), `hoops-late`(@buzzer.kr, "경기 종료 3초 전"). 각 폰 아래 `cl-earn__views` 줄: 플랫폼 아이콘 + 조회수(1.2만 / **31.4만** / 8,400). 가운데 숫자만 `--brand-11` |
| 3 | `ChartNoAxesColumn` | **무엇이 먹히는지, 조회수가 알려줘요.** 같은 경기도 크리에이터마다 장면과 첫 3초, 자막이 달라요. 어떤 영상이 퍼졌는지 캠페인 화면에서 바로 보여요. | 브랜드 앱의 어두운 패널(`cl-app-dark cl-bdemo`, 통제 벤토와 같은 조각). 머리 "받은 클립 · 조회수 순", 다섯 줄: 아바타 · 영상 제목(자막) · "크리에이터 · 플랫폼" · 조회수(오른쪽, 숫자 맞춤). 1위 "이게 들어간다고? · 하린 · 인스타그램 릴스 · 31.4만"만 `--brand-11`. 나머지: 끝까지 보면 소름(도윤·유튜브 쇼츠·1.2만), 경기 종료 3초 전(서아·틱톡·8,400), 골밑 슬로모션 모음(민준·유튜브 쇼츠·5,100), 오늘의 하이라이트(지우·틱톡·3,900) |

- 장면 2와 3은 같은 영상·같은 조회수를 쓴다(앞에서 본 영상이 목록 1위로 이어진다).
- 영상은 장면이 보일 때만 재생한다(지금 히어로 폰과 같은 방식). 움직임 줄이기 설정이면 포스터만 보이고 조회수는 최종값이다.

### 4.3 각주
- 두지 않는다(2026-10-02 사용자 결정). 출처(TikTok Newsroom 2020-06-18)와 1 − 0.8ᴺ 가정은 이 문서 §2에만 남긴다. 장면 1 문장은 출처 인용 없이 쉬운 말로 쓴다.

### 4.4 데이터 섹션에서 빼는 것
- `ViewsStory`의 셋째 숫자 "89% · 영상 10편이면, 하나는 상위 20%"를 뺀다(이 섹션으로 옮김). 숫자 칸은 두 개(8만 원, 90%)가 되고, 넓은 화면은 2열, 좁은 화면은 2열 그대로(셋째 칸 전용 규칙 삭제). 남은 두 숫자의 스크롤 구간은 0.44–0.58, 0.60–0.74로 다시 나눈다.

## 5. 통합 섹션: 정하기만 하면, 나머지는 Clipers가

- 제목: **정하기만 하면, 나머지는 Clipers가** (해결 카드의 제목을 쓴다).
- 형태: 지금 통제 벤토(`cl-bento2`, 작은 카드와 큰 카드가 줄마다 엇갈림)를 그대로 쓴다. 카드는 네 장이다.

| 위치 | 제목 · 설명 | 화면 |
|---|---|---|
| 1행 작은 | **예산과 조건만 정하세요** · 캠페인 종류와 예산, 꼭 지킬 조건을 정하면 준비가 끝나요. ("검수 기준이 돼요"는 데모 아래 줄이 말한다) | `RequirementsDemo` 그대로 |
| 1행 큰 | **클립마다 상한** · 영상 하나가 예산을 독차지하지 않도록, 클립 하나에 쓰일 예산의 상한을 정해요. | `ClipCapDemo` 그대로 |
| 2행 큰 | **승인된 크리에이터가 만들어요** · 크리에이터는 캠페인마다 지원하고, 운영팀이 승인한 사람만 영상을 만들어 올려요. | `ApplicantsDemo` 그대로 |
| 2행 작은 | **나머지는 Clipers가** · 검수, 조회수 집계, 정산과 지급까지 Clipers가 해요. (자동 종료는 데모의 "예산을 다 쓰면 · 캠페인 자동 종료"가 말한다) | `BudgetDemo` 그대로 |

- 해결 카드 섹션(`SolutionCards`)은 없앤다. 그 카드에만 쓰이던 데모(`campaign-editor-demo`, `clip-submit-demo`, `received-clips-demo`)와 프레임 데이터·테스트·스타일(`cl-solution*`)은 다른 곳에서 쓰지 않는지 확인한 뒤 지운다.
- 파일 이름은 `controls-bento.tsx`를 그대로 두고 문구만 바꾼다(섹션 id `controls-title`도 유지).

## 8. 확인 방법
- 타입 검사, 기존 테스트, `brand-reach.test.ts`(조회수 상승 함수의 시작·끝 값, 89% = `round(hitProbability(10) × 100)`)가 통과한다.
- `/brands`와 `/`를 1440×900, 1536×821, 390px에서 캡처한다. 새 섹션의 세 장면 전환, 진행 표시, 좁은 화면에서 쌓인 모습, 크리에이터 페이지 캠페인 종류 섹션이 전과 같은지 본다. 움직임 줄이기 설정에서는 영상이 멈추고 숫자는 최종값이다.
- 데이터 섹션에 숫자가 두 개만 남고, 통합 섹션 카드 네 장의 화면이 잘리지 않는지 본다.
- 렌더링된 HTML에 브랜드 단가가 없고, 새 섹션에 금액이 하나도 없다.
