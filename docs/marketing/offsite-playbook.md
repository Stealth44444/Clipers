# 외부 채널 운영안

> 설계: `docs/superpowers/specs/2026-10-02-advertiser-search-growth-design.md` 6절. 사이트 밖에서 Clipers가 언급되는 곳을 늘리는 계획이다. 네이버는 통합검색에서 블로그·카페 글을 크게 보여 주고, AI 답변은 여러 출처에서 반복해 언급되는 서비스를 신뢰한다. 실행은 팀이 하고, 담당자는 출시 전에 정한다.

## 원칙

- **사실만 쓴다.** 사이트 가이드와 같은 규칙: 브랜드·크리에이터 단가, 지어낸 성과·사례·고객사, 성과 보장, "화면 캡처"로 조회수를 확인한다는 표현은 쓰지 않는다. 다른 플랫폼 조회수는 "운영팀이 영상에 표시된 조회수를 직접 확인"으로 쓴다.
- **회사 계정임을 밝힌다.** 직원이나 회사가 쓰는 글·답변·댓글에는 회사와의 관계를 분명히 적는다("Clipers 운영팀입니다"). 공정거래위원회 추천·보증 심사지침상 경제적 이해관계를 숨긴 추천은 문제가 된다. 손님인 척하는 후기, 지인에게 대가를 주고 쓰게 하는 글은 하지 않는다.
- **원문으로 연결한다.** 외부 글은 요약하고, 자세한 내용은 사이트 가이드 주소로 연결한다. 같은 글을 여러 곳에 그대로 복사하지 않는다(검색엔진이 중복으로 본다).
- **위키 문서를 직접 쓰지 않는다.** 나무위키·위키백과에 회사가 직접 홍보 문서를 만들지 않는다. 언론 보도 등 제3자 출처가 쌓이면 자연스럽게 생긴다.

## 채널별 계획

| 채널 | 무엇을 | 주기 | 연결할 사이트 페이지 |
|---|---|---|---|
| 네이버 공식 블로그 | 가이드 한 편을 블로그 글로 다시 쓴 요약 + 원문 링크. 업종별 사례 글 | 주 2회 | 해당 가이드 |
| 마케터 커뮤니티 (아이보스, 디스콰이엇) | 숏폼 마케팅 비용 구조, 광고 표시 기준, 국내 숏폼 이용 데이터처럼 정보형 글. 회사 계정으로 | 월 2회 | `/guides/short-form-marketing-cost`, `/guides/ad-disclosure-rules`, `/guides/korea-short-form-usage` |
| 유튜브 채널 (쇼츠) | 같은 원본으로 만든 클리핑 예시 여러 버전, 캠페인 여는 과정 화면 | 주 1~2회 | `/brands`, `/guides/clipping-marketing` |
| 링크드인 | B2B 광고주 대상: 업종별 활용법, 데이터 페이지 요약 | 주 1회 | 업종별 가이드 |
| 출시 보도자료 | 서비스 소개, 운영 방식, 회사 정보. 수치는 공개 조사 인용만 | 출시 때 1회 | `/about`, `/brands` |
| 크리에이터 커뮤니티 | 크리에이터 가이드 요약(부업, 수익창출 전 수익) | 월 2회 | 크리에이터 가이드 |

## 글 하나를 만드는 순서

1. 사이트 가이드 중 하나를 고른다(질문 지도 단계를 골고루).
2. 채널에 맞게 다시 쓴다: 블로그는 사례와 이미지, 커뮤니티는 정보 위주, 링크드인은 짧게.
3. 회사 계정 표시와 원문 링크를 넣는다.
4. 올린 날짜·채널·주소를 아래 기록 표에 남긴다.
